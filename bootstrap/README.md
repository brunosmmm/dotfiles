# bootstrap (abandoned)

Unfinished Arch Linux package recipes from around 2019. Nothing in this
repository reads `config.toml` or the files under `recipes/`.

They target X11 (`i3-gaps`, polybar, rofi, betterlockscreen) via pacman/AUR.
This setup now runs Fedora, and the laptop overlay is Wayland/sway.

Do not wire this to `dotupdate`. First-boot steps live in the top-level README.
Keep the sketches only as a historical package list.
